# VOID RUNNER

Monochrome lunar survival driver. Pilot the **VOID HAULER** across a generated mare while Void Stalkers hunt in packs.

**v1.0.0** — initial public release.

## Controls

| Action | Keyboard | Gamepad |
| --- | --- | --- |
| Drive | WASD / Arrows | Left stick |
| Look | Mouse (click to lock) | Right stick |
| Fire | Space / F / click | A |
| Handbrake | C / Ctrl | LB / RB |
| Overdrive | Shift (after a boost orb) | B |
| Pause | Esc / P | Start |
| Mute | M | — |
